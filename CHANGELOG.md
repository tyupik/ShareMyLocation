# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат: секция `## [версия] — дата`, изменения группируются по разделам
(Добавлено / Изменено / Исправлено). Перед релизом актуальная секция
копируется в описание GitHub Release автоматически (см. `.github/workflows/android-release.yml`).

## [Unreleased]

### Добавлено

- Дизайн-концепция AURORA «ночной неон»: тёмная палитра Material 3, шрифт Manrope,
  крупные скругления (12/16/22/28dp), градиентные акценты индиго → циан.
- Тёмный стиль Google-карты (`res/raw/map_style_aurora.json`): ночная схема дорог, воды,
  парков и подписей.
- Неоновые кольца маркеров друзей: цвет кольца детерминированно по uid из палитры
  `MARKER_NEON_COLORS`.
- Общие UI-компоненты: GlassCard, GradientPrimaryButton, ErrorBanner, LoadError,
  AuroraBackdrop (фоновое свечение), GlassIconButton, auroraOutlinedTextFieldColors.
- Backdrop-blur нижней навигации (Haze): панель размывает контент за собой; на вкладке
  «Карта» остаётся полупрозрачным тонированным стеклом (SurfaceView карты блюром
  не захватывается).
- Иконка Google (четырёхцветная «G») на кнопке входа через Google.
- Анимация «перекатывания» градиентной пилюли активного таба (пружина с лёгким
  overshoot) и «пульс в такт» при переключении.

### Изменено

- Редизайн всех экранов (auth, profile setup, навигация, карта, друзья, группы, шаринг,
  профиль): стеклянные карточки, градиентные кнопки, плавающая нижняя навигация.
- Дубликаты UI-элементов (6 баннеров ошибок, 4 load-error, 3 submit-кнопки) заменены
  общими компонентами `ui.common.composable` без изменения MVI-контрактов.
- `enableEdgeToEdge` с прозрачными системными барами и светлой иконографией,
  тёмный `windowBackground` в теме приложения.
- Карта рисуется на весь экран (edge-to-edge): нативные zoom-контролы/компас и плавающие
  кнопки карты поднимаются над навбаром и статус-баром через contentPadding.

### Исправлено

- Здания вернулись на тёмный стиль карты: базовое правило `geometry → #0C1224`
  перекрашивало их; добавлены явные правила `landscape.man_made` (заливка + контур).

## [1.0.1] — 2026-10-25

### Исправлено

- Краш release-APK при запуске: `java.lang.IllegalAccessError: Class kotlin.text.f extended by class i92`.
  Причина — оптимизация `optimization.packageScope` (приватизация классов `kotlin.**` в R8);
  оптимизация отключена, обычная минификация release сохранена. Найдено при проверке
  релизного APK на устройстве.

## [1.0] — 2026-10-25

Первый публичный релиз.

### Добавлено

- Аутентификация: email + пароль и вход через Google (Credential Manager), MVI + Hilt.
- Профиль и онбординг: имя, телефон, аватар в Firestore; съёмка аватара с камеры и круговое
  кадрирование (android-image-cropper).
- Главный экран с нижней навигацией: Карта / Друзья / Профиль.
- Друзья: поиск по телефону, заявки в обе стороны, список друзей в realtime,
  подтверждение удаления друга.
- Добавление друга из телефонной книги с нормализацией номеров к виду 8XXXXXXXXXX.
- Группы друзей: секция на вкладке «Друзья» и редактор группы.
- Шаринг геолокации: настройка видимости (всем друзьям / группе), foreground-сервис
  отправляет координаты каждые 5 секунд в `locations/{uid}`.
- Карта: локации шарящих друзей в realtime, аватар-маркеры, метки давности
  («Только что», «30 секунд назад»).
- Уведомления: заявка в друзья, начало шаринга геолокации другом.
